# PhysioLink 💪🧠

PhysioLink is a web-based application designed to digitalize the physiotherapy experience by connecting specialists and patients through a single platform.The project focuses on improving exercise guidance, follow-up, and accessibility outside the clinic.


<br /><br />

---------------

## 📌 Project Overview

Physiotherapy patients often struggle with:
- Losing or forgite exercise instructions
- Performing exercises incorrectly at home
- Lack of continuous follow-up after clinic visits

**PhysioLink** solves this by providing:
- A clear and visual exercise experience
- Digital connection between specialist and patient
- Centralized management of exercises and patients
- Easy access to assigned exercises anytime

---

## 👥 Users

### 👩‍⚕️ Specialist
- Log in to the system
- Create, edit, and delete exercises
- Add and manage patients
- Assign exercises to patients

### 🧑‍🦽 Patient
- Log in to the system
- View assigned exercises
- Access exercise details
- Follow exercises at home correctly

---

## ▶️ How to Run the Project

Follow the steps below to run the project locally:

### 1. Clone the repository
```bash
git clone https://github.com/manar-d/PhysioLink.git

```
2. Navigate to the project directory
```bash
cd physiolink
```
3. Install dependencies
```bash
npm install
```
4. Start the development server
```bash
npm run dev
```
5. Open the application in your browser
```bash
http://localhost:5173
```
⚠️ Note
This project uses LocalStorage as a mock database, so no backend or database setup is required.

## 🛠 Technologies Used
- React.js – Frontend framework
- Vite – Development environment and build tool
- React Router DOM – Routing and navigation
- Context API – Global state management 
- Custom Hooks – Reusable business logic
- Material UI (MUI) – UI components and styling
- React Hook Form – Form handling
- Yup – Form validation
- LocalStorage – Mock database for storing data
